## この章でやること

取得したVPCに付与するインターネットゲートウェイを作成します。

> 📍 **デプロイ全体フロー（現在地）**  
> ① VPC → ② サブネット → **③ IGW** → ④ ルートテーブル → ⑤ セキュリティグループ → ⑥ RDS → ⑦ ECR → ⑧ コード準備 → ⑨ タスク定義 → ⑩ ALB → ⑪ サービス起動 → ⑫ CD自動化

### なぜIGWが必要か

VPCを作成しただけでは、外部（インターネット）との通信は**完全に遮断**されています。IGWはVPCに「外との出入り口（玄関ドア）」を付ける作業です。ただし、IGWを作っただけではまだドアが開きません。次章のルートテーブルで「どのサブネットがこのドアを使えるか」を設定して初めて開通します。

## インターネットゲートウェイとは？

**インターネットゲートウェイ** とは、VPCとインターネットとの間の通信を可能にするための部品です。

AWSサービスの大原則として、 **AWS内で作成したあらゆるものは、自身の外側との通信が一切遮断された状態をデフォルトとしています** 。AWS内で作成したものが意図しないところで勝手にどこかを通信できてしまうのは、セキュリティの観点からリスクになるからです。

VPCの場合、取得した土地の外側とのやり取りが一切禁止されている状態からのスタートになります。四方を柵に覆われているようなイメージです。

この柵に取り付ける、外の人間とやりとりをできるような扉となるのが **インターネットゲートウェイ** になります。

## 手順

VPCダッシュボードから「インターネットゲートウェイ」にアクセスし、「インターネットゲートウェイの作成」を押下します。

![](https://static.zenn.studio/user-upload/a9f3e8813553-20230514.png)

↓

名前を入力して、「インターネットゲートウェイの作成」を押下します。

| 項目 | 値 |
| --- | --- |
| 名前タグ | zenn-clone-internet-gateway |

↓

インターネットゲートウェイが正常に作成されたら、詳細画面右上の「アクション」から、「VPCにアタッチ」に入ります。

![](https://static.zenn.studio/user-upload/66f346ec991b-20230514.png)

↓

作成したVPC（zenn-clone-vpc）を選択して、「インターネットゲートウェイのアタッチ」を押下します。

![](https://static.zenn.studio/user-upload/a303bfbe0d3c-20230514.png)

↓

アタッチが正常に完了すればOKです！

![](https://static.zenn.studio/user-upload/aaba082e91ca-20230514.png)

## ✅ この章の完了確認

- [ ] IGW一覧に `zenn-clone-internet-gateway` が表示されている
- [ ] 状態が「アタッチ済み」になっている
- [ ] VPC IDが `zenn-clone-vpc` になっている

> ⚠️ **注意**：IGWはVPCに1つしかアタッチできません。「デタッチ済み」のままだと次章のルートテーブル設定が無意味になります。
